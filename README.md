\# StaticForge - CLI Static Site Generator



StaticForge is a pure Core Java CLI tool that converts markdown-formatted files into linked static HTML pages with an auto-generated index and keyword search engine.



\## Prerequisites

\- Java Development Kit (JDK 17 or later)

\- Terminal / Command Prompt
